# Hridyaa Image Compressor and Optimizer

High-performance, lightweight Next-Generation WebP & AVIF Image Optimizer for WordPress.

## Description
Hridyaa Image Compressor and Optimizer automatically converts your uploaded JPEG and PNG images into modern, next-generation WebP (and AVIF) formats, drastically reducing page weight and boosting Core Web Vitals (LCP/PageSpeed) scores without sacrificing visual quality.

## Features
- Automatic WebP conversion on upload via GD or Imagick
- Bulk optimization runner with AJAX and Background Queue processing
- Quality Visualizer comparison slider
- Picture-tag multi-tier delivery fallback
- Fully compatible with WordPress 6.0+ and PHP 7.4 - 8.3+
