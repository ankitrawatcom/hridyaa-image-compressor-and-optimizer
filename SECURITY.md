# Security Policy

## Supported Versions

Only the latest release branch of Hridyaa Image Compressor and Optimizer receives active security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.2.x   | :white_check_mark: |
| < 1.2.0 | :x:                |

## Reporting a Vulnerability

We take the security of Hridyaa Image Compressor and Optimizer seriously. If you discover a security vulnerability, please report it responsibly.

### Reporting Procedure
- **Email:** `security@ankitrawat.com`
- **Subject Line:** `[Security Report] Hridyaa Image Compressor - <Brief Summary>`
- **Include:**
  - Detailed description of the vulnerability.
  - Clear steps to reproduce or Proof of Concept (PoC).
  - Potential impact assessment.
  - Affected versions and WordPress / PHP environment details.

### Response Timeline
- **Acknowledgment:** Within 48 hours of initial receipt.
- **Assessment & Fix:** Priority triage, patch development, and scheduled release.
- **Coordination:** We request coordinated disclosure until a security release is published.
